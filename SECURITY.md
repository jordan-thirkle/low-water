# Security policy

## Reporting

Please do not open a public issue for a suspected security vulnerability.
Contact Jordan Thirkle through the private contact method listed on the GitHub
profile and include a reproducible description, affected version, and impact.

Do not include passwords, access tokens, Supabase service-role keys, private
player data, or other secrets in a report.

## Scope

Before public release, the project must add authoritative server validation,
chat moderation/rate limits, account deletion, retention rules, and a complete
dependency/artifact audit. Until then, the live room transport is a prototype
and must not be used for competitive progression.
